Frequently Asked Questions

These answers describe the current storefront and backend-confirmed Paystack flow.

1How do I pay for products?

Add products to your cart, enter the requested customer and delivery details, give explicit WhatsApp consent, and continue to Paystack's hosted checkout. Kawama's backend recalculates the product amount before payment starts.

2How is payment confirmed?

The payment-result page checks Kawama's backend. A Paystack redirect, reference in the address bar, or browser message is not proof of payment. Only a backend-confirmed paid status completes the order and updates the cart.

3Does the Paystack amount include delivery?

No. Paystack collects the backend-confirmed product amount only. Delivery is quoted separately and paid on delivery. A delivery fee that has not been quoted is not the same as free delivery.

4What if I return from Paystack without paying?

Returning does not cancel the server checkout or its stock reservation. The result page checks the saved checkout status, polls for a limited time, and provides a manual recheck when confirmation is still pending.

5What is WhatsApp used for?

After a backend-confirmed product payment, WhatsApp is an optional way to coordinate delivery using the public order number. It does not create a second purchase request and is not required to start Paystack payment.

6What are the return and refund terms?

Kawama has not published complete return or refund terms yet. Review the Delivery & returns information for the verified flow and the details still missing.
